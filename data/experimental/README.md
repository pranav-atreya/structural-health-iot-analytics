# Experimental Data

Store reviewed datasets captured from the actual prototype here.

For each experiment, record:
- unique run ID
- date/time
- experiment condition
- applied mass and placement (for static-load trials)
- vehicle crossing count and trial notes (for dynamic trials)
- sensor calibration factors
- sampling and reporting settings
- any anomalies or excluded intervals

Do not place synthetic/demo records here. Synthetic test data belongs in `data/sample/` and must be labelled clearly.

Never commit Wi-Fi passwords, ThingSpeak API keys or MQTT credentials.
